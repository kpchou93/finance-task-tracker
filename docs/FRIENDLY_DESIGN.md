# Friendly finance design

The supplied `stitch_friendly_cheerful_app_mockup.zip` provides the Warm Welcoming Pastel Wellness palette, Plus Jakarta Sans typography, flower logo reference, rounded surfaces and mobile navigation. These visual references are adapted to the existing finance application, including its dashboard, task/company forms, authentication and team management.

Cream backgrounds, coral actions, mint completion states, sunny due-date cards and lavender progress indicators retain readable dark text. The dashboard progress banner derives its count and percentage from the current workspace's actual tasks. On phones, a safe-area-aware navigation dock links to working routes. Sidebar navigation remains available for switching workspaces and account controls. All database actions and tenant isolation are unchanged.

Plus Jakarta Sans is bundled locally with its SIL Open Font License. The flower mark uses native SVG; no reference scripts, remote avatars, placeholder notification buttons or wellness features are introduced.
